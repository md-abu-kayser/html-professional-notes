# 03 — Forms & Input

> 🚧 **Status:** Syllabus ready — 9 lessons outlined, full content in progress.

A deep dive into HTML forms — the part of the language with the most surface area and the most opportunity to either delight or frustrate a user, before a single line of JavaScript gets involved.

## Lessons

| # | Lesson | Covers |
|---|---|---|

| 02 | [Input Types Text Password Email Number Date Etc](./02-input-types-text-password-email-number-date-etc.md) | The full range of HTML5 `<input>` types and the validation/UI each one gets for free. |

| 05 | [Textarea and File Input](./05-textarea-and-file-input.md) | Multi-line text entry with `<textarea>` and file uploads with `<input type="file">`. |
