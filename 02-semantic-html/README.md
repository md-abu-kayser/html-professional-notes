# 02 — Semantic HTML

> 🚧 **Status:** Syllabus ready — 8 lessons outlined, full content in progress.

The module that separates markup from *professional* markup: choosing elements for what they mean, not just how they render, and why that choice ripples into accessibility, SEO, and long-term maintainability.
